## Requirements

- Windows 10/11 or Linux
- Python 3.11+
- Ghidra 12.1.3
- JDK required by Ghidra
- Qwen 7B model (later)

## Setup

1. Install Ghidra.
2. Clone this repository.
3. Create a Python virtual environment:

   python -m venv .venv

4. Activate the environment:

   .\.venv\Scripts\Activate.ps1

5. Install the project:

   pip install -e .
